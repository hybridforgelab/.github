# Security policy

## Reporting a vulnerability

Please **don't open a public issue** for a security problem.

Email **hybridforgelab@gmail.com** with:

- the repository (or the API / site) affected;
- what you found and how to reproduce it;
- what an attacker could do with it, as far as you know.

We'll acknowledge your report within a few working days, keep you updated while we fix it, and credit you in the
release notes if you want to be credited.

## Scope

This covers the public repositories in the [hybridforgelab](https://github.com/hybridforgelab) organization and the
services they talk to (our APIs, sites and demo gateway). Please test only against your own accounts and keys, and
don't run load tests or anything that could degrade the service for other people.

## Supported versions

We fix security issues in the latest release of each project.
