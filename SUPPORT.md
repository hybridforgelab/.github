# Getting help

- **A bug or an idea for the code in a repository:** open an issue in that repository.
- **Questions about one of our APIs** (plans, keys, limits, results), or a problem with a subscription: use the
  [contact page](https://hybridforgelab.com/contact.html). Plans and keys are managed on
  [RapidAPI](https://rapidapi.com/user/hybrid-forge-lab-hybrid-forge-lab-default).
- **Security issues:** see [SECURITY.md](SECURITY.md); never in a public issue.

Each product site also has documentation and a live demo: see [hybridforgelab.com](https://hybridforgelab.com).
